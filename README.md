# 📚 ScholarOS

ScholarOS is a simple all-in-one student productivity web app built with Django.  
It helps students stay organized, track study progress, and improve consistency.

---

## 🚀 Features

- 📊 Dashboard with study analytics
- 🎓 CGPA calculator
- 📅 Interactive study calendar
- ⏱ Pomodoro timer
- 📝 Task tracking system
- 🔐 User authentication (login/register/logout)

---

## 🛠 Tech Stack

- Django (Python)
- HTML + Tailwind CSS
- JavaScript
- Chart.js
- SQLite (default database)
